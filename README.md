# E-Commerce Platform

A browser-based e-commerce platform built using HTML, CSS, and JavaScript. Users can browse products, view product information, and manage their shopping cart.

## Features

- Responsive e-commerce interface
- Product search by keyword
- Product filtering by category
- Product filtering by price
- Product details page
- Add, remove, and update products in the shopping cart
- Frontend order confirmation flow
- Dynamically loaded product and category data from JSON files

## Technologies Used

- HTML 5
- CSS 3
- JavaScript
- Git & GitHub
